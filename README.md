# 🦖 ARK Dino Color Generator

[🇵🇱 Przejdź do polskiej wersji (Polish version below)](#-ark-dino-color-generator---wersja-polska)

---

A modern, responsive web application for choosing dino color combinations and generating ready-to-use commands for **ARK: Survival Ascended (ASA)** and **ARK: Survival Evolved (ASE)**.

Designed for seamless in-game styling, server administration, and plugin support. Hosted on **GitHub Pages** with zero setup required.

👉 **Live Demo:** [https://leesha93.github.io/ASA-dino-color-generator/](https://leesha93.github.io/ASA-dino-color-generator/)

---

## 🌟 Key Features

- 🎨 **Full ARK Color Database (227 Colors)**:
  - Exact IDs, official names, and HEX preview values extracted directly from the official ARK color tables.
  - Includes standard colors, seasonal event shades, and rare variants.
- ✨ **Color Theory & Harmonic Palettes**:
  - Roll coordinated color schemes powered by color harmony algorithms (Analogous, Complementary, Split-Complementary, Triad, Monochromatic).
  - Select mood aesthetics: *Natural / Animalistic*, *Vibrant / Neon*, *Dark / Predator*, or *Sweet / Pastel*.
  - Lock anchor regions (🔒) to generate harmonies radiating from a chosen base color.
- 🎪 **Thematic & Event Presets**:
  - Official ARK Events: *Winter Wonderland*, *Love Ascended*, *Eggcellent Adventure*, *Summer Bash*, *Fear Ascended*, *Turkey Trial*.
  - Curated Aesthetic Styles: *Alpha*, *Cosmic*, *Dragon Fire*, *Nordic Frost*, *Sweet Pastel*, *Synthwave*, *Reef Lagoon*, *Royal Amethyst*.
- 👁️ **Interactive Pool Manager**:
  - Inspect currently active pool colors and selectively exclude / blacklist specific shades with one click.
  - Fine-tune random rolls by color tags and categories.
- 🦖 **Full 6-Region Support (Regions 0–5)**:
  - Toggle individual regions on/off for creatures with fewer color regions.
  - Lock individual regions (🔒) to preserve favorite colors during rolls.
  - Interactive preview bar with drag-and-drop / swap and insert controls.
- 📋 **Dual In-Game Command Generator**:
  - **Admin / Cheat Console**: `cheat settargetdinocolor <region> <id> | ...`
  - **Chat Command / Server Plugin**: `/color <r0> <r1> <r2> <r3> <r4> <r5>` (with live two-way editing).
  - One-click copy buttons with instant feedback.
- ⭐ **Favorites & History Library**:
  - Save custom color sets with custom names.
  - Automatic rolling history to recover previous compositions.
- 🔍 **Fast Search & Modal Views**:
  - Search by name, ID number, or HEX code.
  - Toggle between Standard card view and Compact grid mode.
  - Favorite individual colors (⭐) to build your personal selection pool.
- 🌐 **Bilingual (EN / PL)**:
  - Complete internationalization with instant English / Polish toggle.
- ⚡ **Lightweight & Dependency-Free**:
  - 100% Vanilla JS, HTML5, and modern CSS. No build step or `npm` dependencies.

## 🎮 How to Use

1. **Configure Regions**: Select colors manually for regions 0–5 or click **🎲 Roll all** / **✨ Roll in harmony**.
2. **Lock or Disable**: Click the lock icon (🔒) to protect a region from being rerolled, or click the power icon (⏻) to disable unused regions.
3. **Filter the Pool**: Use event chips, aesthetic style presets, or color tags to constrain which colors can be rolled.
4. **Copy & Apply**:
   - For singleplayer / server admins: Target your dino and paste the **Admin Console / Cheat** command.
   - For modded / plugin servers: Paste the **/color** chat command in global chat.
5. **Save**: Click **⭐ Save set** to store your creation in your local library.

## 🎮 Instrukcja obsługi

1. **Dobierz barwy**: Wybierz kolory ręcznie dla slotów 0–5 lub kliknij **🎲 Losuj wszystkie** / **✨ Losuj w harmonii**.
2. **Zabezpiecz sloty**: Kliknij kłódkę (🔒), by uchronić dany kolor przed zmianą, lub wyłącz nieużywane regiony przyciskiem zasilania (⏻).
3. **Dostosuj pulę**: Wybierz oficjalny event ARK, styl lub zaznacz wybrane odcienie, by ograniczyć zakres losowanych kolorów.
4. **Skopiuj komendę**:
   - W trybie jednego gracza lub na własnym serwerze naceluj na dinozaura i wklej komendę **Konsola Admina / Cheat**.
   - Na serwerach z pluginem wklej na czacie gotową komendę **/color**.
5. **Zachowaj paletę**: Kliknij **⭐ Zapisz zestaw**, by dodać go do swojej kolekcji.
